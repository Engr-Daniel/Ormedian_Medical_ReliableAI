# Figures

Keep small teaching and research figures used for interpretation here. Use descriptive names, including a unit or experiment ID where relevant. Record a caption, axis labels/units where applicable, the source data or example, and the script/notebook or steps that regenerate the figure.

Link related [results](../results/README.md) and [execution records](../experiments/README.md). Identify conceptual diagrams and illustrative examples so they are not mistaken for measured results. Check that images contain no identifiable patient information.

Ordinary PNG, SVG, JPEG, and small figure PDFs are eligible for Git; the directory is not ignored. Keep large exports outside Git and prefer reproducible source. Research-paper PDFs are prohibited even if placed here. No figures have been generated yet.

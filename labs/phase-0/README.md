# Phase 0 Labs

Labs are guided practice activities completed **before** the corresponding assessment.

A lab is not the place to store answers to the formal assessment. It should help the trainee practise the unit's reasoning, technical, debugging, or research workflow.

For P0-U01, the lab may be a reasoning lab rather than executable code.

Use the unit ID in filenames, for example:

`P0-U01_researcher_mindset_lab.md`

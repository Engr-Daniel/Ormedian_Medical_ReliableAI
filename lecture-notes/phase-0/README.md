# Phase 0 Lecture Notes

This directory contains the durable teaching notes for Phase 0 learning units.

Lecture notes are distinct from:

- `curriculum/` — sequence, objectives, pacing, navigation, and completion expectations;
- `labs/` — guided practice completed by the trainee;
- `slides/` — trainee teach-back artifacts showing their understanding;
- `assessments/` — independent competency checks;
- `research-notes/` — reflections, reasoning, reading notes, and research journal entries.

## Naming

Use the stable learning-unit ID in every lecture-note filename.

Example:

`P0-U01_Lecture_Notes_Researcher_Mindset_and_Scientific_Workflow.docx`

Each major lecture should include carefully selected further-reading recommendations. External readings supplement the lecture; copyrighted paper/book PDFs should not be committed to this repository.

# Phase 0 Assessment Submissions

Keep completed trainee responses separate from reusable assessment documents.

Example:

- Assessment: `../P0-A01_Assessment_Researcher_Mindset_and_Scientific_Workflow.docx`
- Submission: `P0-A01_research-reasoning-Daniel.docx`

Do not commit sensitive personal information. If this curriculum is later used by multiple trainees, the team should decide whether individual submissions belong in the shared public repository or in a private training repository.

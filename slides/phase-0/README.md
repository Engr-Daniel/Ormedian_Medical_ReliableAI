# Phase 0 Slides

Slides are **trainee teach-back artifacts**: concise presentations showing what the trainee understood from the lecture, reading, and lab.

They should not simply reproduce the lecture notes.

Canonical source format: Marp Markdown (`.md`).

Use the unit ID and, where useful, the trainee identifier in the filename, for example:

`P0-U01_researcher_mindset_Daniel.md`
